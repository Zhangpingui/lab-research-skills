# 论文实验、结果与图表设计

本流程用于让每项实验和每幅图表承担明确的论证任务。先确认论文主张，再设计证据；不能先生成大量结果后再挑最有利的图解释。

## 建立实验矩阵

为每条主要主张建立一行：

| 字段 | 应回答什么 |
|---|---|
| `claim_id` | 这项实验验证哪条主张？ |
| 问题 | 为什么需要这项实验？ |
| 自变量 | 唯一或主要改变什么？ |
| 控制条件 | 哪些数据、训练预算、硬件和处理保持一致？ |
| 基线 | 最接近方法、标准方法或必要下界/上界是什么？ |
| 数据/场景 | 数据来源、划分、传感器、环境和样本单位是什么？ |
| 指标 | 指标定义、统计口径和工作点是什么？ |
| 重复性 | 随机种子、重复次数、离散程度或置信区间如何处理？ |
| 预期区分 | 哪种结果支持主张，哪种结果支持竞争解释？ |
| 停止条件 | 什么结果会削弱、收缩或推翻主张？ |
| 资源 | 需要的代码、数据、设备、算力和时间是否已有？ |

输出 `experiment-matrix.md`。缺少条件时写 `unknown`，不要用常见默认值填充真实实验。

## 最小充分证据集

根据论文主张选择实验，不要求机械包含所有类型：

- **主结果**：在目标任务和公平设置下验证总体效果；
- **消融**：区分收益来自核心设计还是额外参数、数据、预处理或训练预算；
- **敏感性**：验证关键参数、阈值或假设变化后的趋势；
- **鲁棒性/泛化**：只在论文声称跨噪声、杂波、场景、传感器或数据集有效时要求；
- **复杂度/资源**：参数量、FLOPs、时延、显存、功耗或测量成本与论文主张匹配；
- **失败案例**：展示适用边界、典型误检漏检或方法退化条件；
- **理论—实验对应**：用实验检查理论趋势、界或近似是否在声明条件下出现。

每项实验写清“为什么做—怎么做—观察到什么—支持哪条主张—仍不能证明什么”。

## 公平比较

比较前核对输入信息、数据划分、预训练、增强、训练轮数、调参预算、后处理、阈值和硬件。无法完全对齐时显式说明差异，不写成严格优越性结论。

绝对提升、相对提升和百分点分别计算。速度必须记录硬件、batch、精度模式以及是否包含预处理/后处理。均值之外是否需要标准差、置信区间或显著性检验由研究设计和样本结构决定，不能为显得严谨而机械添加。

## 结果图表消息表

在绘图前生成 `figure-plan.md`：

| 图表 | 对应主张 | 一句话消息 | 数据/条件 | 选择该形式的理由 | 风险 |
|---|---|---|---|---|---|

一幅图优先承担一到两个可复述消息。两幅图传达相同结论时合并或删减；一个关键结论需要多种证据时说明各自区分的变量。

图表形式按表达任务选择：

- 趋势或连续变化：折线图；
- 相关性、分布或理论偏差：散点图；
- 离散类别比较：条形图；
- 连续变量分布：直方图或合适的分布图；
- 精确数值和多指标比较：表格；
- 算法步骤和决策：流程图；
- 系统、阵列、成像和模块关系：示意图。

饼图、3D 效果、装饰背景和过密网格通常不利于精确比较；只有表达目的确实需要时使用。

## 图和表的自明性

只看图、图题、图例和必要图注时，应能知道实验对象、关键条件、横纵轴/单位、比较对象和主要消息。

- 坐标名称、单位、范围、线型、标记和图例顺序保持一致；
- 不只依赖颜色区分曲线，保证黑白打印和常见色觉差异下可读；
- 误差条说明标准差、标准误还是置信区间；
- 坐标范围不得通过截断制造夸大差异；使用对数轴时说明原因；
- 同类图保持尺寸、字体和比例一致；
- 表格中同类数据放同一列，小数精度和单位一致；
- 图表在正文中均被引用，并由正文解释而不是让读者自行猜测。

保留可编辑图源和生成代码。输出格式服从目标期刊；不把 EPS、PDF、SVG 或某个绘图软件设为统一硬规则。

## 雷达、阵列、SAR 和小目标检测检查

根据任务选用 [领域要点](domain-radar.md)，并至少核对：

- 雷达检测：信号、噪声/杂波模型，SNR/SCNR，检测率与虚警率的定义、分母和工作点；
- 相控阵：频段、阵元/口径、互耦、幅相误差、校准、扫描角、极化、增益/方向性和旁瓣口径；
- SAR：传感器、频段/极化、分辨率、成像/预处理、复数/幅度/强度数据以及原始大图或航迹级泄漏；
- 小目标检测：任务类型、目标尺度、IoU/匹配/NMS、切片合并、类别不平衡、预训练和训练预算；
- 工程主张：仿真、公开数据和实测分别支持到哪一层，不能相互替代。

## 写入正文前的检查

- 图表中的数字与正文、摘要和结论一致；
- 每项核心贡献至少有一条直接证据或明确待补状态；
- 负面结果和失败案例没有被选择性隐藏；
- 结果支持的是相关性、机制、性能还是可行性，措辞没有越界；
- 竞争解释有必要对照，或在讨论中保留未解决状态。

缺少关键对照、数据划分或指标定义会改变结论时，停止撰写确定性结果，先交付实验缺口和补证方案。

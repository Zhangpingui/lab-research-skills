# 从论文到改进思路

根据已读论文、研究者观察和资源条件提出候选，不把网络结构拼接或换数据集直接当作创新。

## 找到值得检验的差异

优先寻找论文已暴露的失效条件、尚未区分的解释、未验证的假设、模型与真实条件的不匹配。每个机会至少说明来自哪个结果、哪个限制或哪个研究者观察。

若要判断新颖性，检索最接近且可能否定新意的已有工作，比较问题、假设、方法和验证条件。未找到相似工作仅意味着在本次检索范围内未找到；不能写成领域空白。

## 每个候选的最小内容

| 内容 | 应回答什么 |
|---|---|
| 依据 | 哪个证据或观察触发这个想法？ |
| 问题/假设 | 想弄清什么关系、规律、可辨识条件或性能边界？ |
| 改动 | 改模型、先验、损失、校准、采样还是评价？为何可能有效？ |
| 最接近工作 | 与已知方法实质区别是什么？未查新则标记未查新 |
| 最小验证 | 用什么数据/仿真/测量，比较哪些条件？ |
| 竞争解释 | 是否只是增加数据、参数、计算或调参预算带来的收益？ |
| 失败条件 | 什么结果会使假设不成立或需要重构？ |
| 资源 | 已有、缺失、未知的设备、数据、时间或计算资源 |

按证据与投入给出“可优先试验、需先补证据、暂缓”的建议和理由；可以没有值得推荐的候选。不提供看似精确的创新评分或中标概率。

## 示例：SAR 检测（假设性说明，不是查新结论）

输入观察：研究者发现某方法在跨传感器测试时下降，原因尚未确定。

候选问题：下降主要与辐射分布差异、分辨率变化还是场景构成有关？某种物理一致性约束能否改善其中一种失配？

最小验证：先在保持训练预算一致的前提下，按传感器与场景组织独立测试，分别改变归一化、分辨率处理和约束项；记录检测指标及虚警口径。具体数据划分由真实数据决定。

竞争解释：收益可能来自额外预处理、训练数据增加或更大的模型。

失败条件：匹配训练预算与预处理后收益消失，或只对特定场景有效。前者削弱所提约束的解释，后者提示应缩小适用范围。

继续写基金前，需要作者判断这个问题是否重要、是否已有充分研究，以及本组是否具备验证条件。
